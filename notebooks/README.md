# Notebooks

This folder contains the Jupyter Notebook implementation of the project.

## Files

- `primal_dual_algo.ipynb` - Main notebook implementing the Primal-Dual Learning Algorithm for inventory-constrained dynamic pricing.

## Notebook Overview

The notebook includes:

- Demand simulation for multiple customer types
- Logistic demand curve generation
- Exploration phase for testing prices and observing demand
- Dual variable estimation using numerical optimization
- Random Forest-based demand estimation
- Exploitation phase for inventory-aware pricing
- Revenue calculation
- Oracle benchmark comparison
- Regret calculation
- Visualization of price-demand and price-revenue relationships
