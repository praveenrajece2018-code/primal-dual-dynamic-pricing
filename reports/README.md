# Reports

This folder contains the academic project report and supporting documentation for the project.

## Files

- `project_report.pdf` - Final project report for the Primal-Dual Learning Algorithm implementation.

## Report Overview

The report explains the complete project methodology, including:

- Problem formulation for inventory-constrained dynamic pricing
- Primal and dual optimization concepts
- Exploration and exploitation phases of the algorithm
- Dual variable estimation
- Demand generation using logistic demand curves
- Demand estimation using Random Forests
- Revenue and regret analysis

## Purpose

This folder is included to provide detailed academic documentation of the project, including the theoretical background, implementation logic, and experimental results.
